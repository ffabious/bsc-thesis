# Завершение работы

- По умолчанию после задачи с изменением файлов проверь результат, создай коммит и отправь его непосредственно в `origin/main`. Дополнительное подтверждение пользователя для коммита и пуша не требуется.
- Явная просьба пользователя оставить изменения локально, не коммитить, не пушить или использовать другую ветку имеет приоритет над этим правилом.
- Включай в коммит изменения выполненной задачи. Уже существующие изменения от других задач сохраняй отдельно, если пользователь не поручил их опубликовать.
- Используй обычный push без принудительной перезаписи истории. При расхождении с удалённой веткой сначала интегрируй её изменения с сохранением работы пользователя.
- После пуша проверь синхронизацию локальной и удалённой веток. В ответе укажи коммит и результат отправки; при ошибке сообщи, что осталось локально и почему.
