# Watt: отменённая попытка запуска

9 ноября 2026. Пользователь отменил Watt и поручил продолжить только локальное обучение.

Планировался один Vanilla job **Model Training** на Watt, pool `research_gpu`, tree `gpu_hainan_80g`: 1 GPU, 1 CPU, 2 GiB RAM, 2 GiB disk. Аутентифицированный пользователь и право использования пула были проверены: `k-greshnov`.

**Операция не создана, GPU не выделялись, train/validation не загружались.** При создании приватного временного каталога сервер отказал в праве `administer` на родительский `//tmp`. Автоматическая проверка отклонила вариант с общим `//tmp` из-за доступа других пользователей. Последующая проверка пустого каталога подтвердила отсутствие права менять его ACL; созданный пустой каталог удалён после отмены. В поддержку ничего не отправлялось.

- `launch_watt_sasrec.py` — черновик отправки операции, **не запускать из архива**. Он не является проверенным рабочим launcher и не обеспечивает приватный storage; для возобновления сначала нужен согласованный приватный путь.
- `watt_sasrec_job.py` — черновик CUDA entrypoint с сохранением checkpoints в YT.
- `sasrec-1k-large-recent-cuda.json` — конфигурация с одним CPU-потоком.
- `cuda-support.patch` — изолированные CUDA-добавления, удалённые из активного кода после отмены. Основной код снова поддерживает только CPU/MPS.
- `outcome.json` — итог без credentials и исходных пользовательских строк.

Локальный bundle с train/validation, служебные metadata и лог перемещены в игнорируемый `data/archive/watt-2026-11-09/`; они не попадают в Git. Bundle содержит только код, config и train/model_valid, без test и аудиовекторов. Токены в bundle и репозитории не сохранялись. Архивные скрипты используют прежнее расположение относительно корня репозитория и требуют восстановления/проверки перед применением.
