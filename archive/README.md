# Архив импорта

`import-2026-10-20/` сохраняет происхождение материалов первого коммита:

- `README.txt` и `MANIFEST.json` — исходные описание и манифест внешнего архива; пути в них относятся к прежней структуре.
- `import-map.json` — соответствие всех файлов внешнего архива новым путям, контрольные суммы, распаковка вложенных ZIP и происхождение двух локальных заметок.
- `bundles/` — три исходных вложенных ZIP без изменений.
- `snapshots/literature-2026-10-11/` — полностью распакованный прежний комплект литературы из 75 работ.
- `literature-README.txt` — исходная памятка литературного комплекта, также описывающая прежнее состояние.

Оба вложенных архива шаблона распакованы и побайтово совпадают с `thesis/` от корня репозитория. Их содержимое хранится в одном экземпляре. Актуальный реестр из 78 работ находится в `references/` от корня репозитория.
