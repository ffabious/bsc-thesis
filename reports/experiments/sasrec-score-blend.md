# Смешивание оценок SASRec 50/2 после нормировки шкал

9 ноября 2026. Все вычисления локальны на Apple M3 Pro, MPS, FP32, CPU fallback отключён. Использованы готовые joint-BCE checkpoints; модели не переобучались. [Протокол](../../configs/experiments/sasrec-score-blend.json), [код](../../scripts/blend_sasrec.py), [предыдущие модели](sasrec-recent-2.md).

**Оба независимо выбранных веса: α = 0.6 для короткой модели и 0.4 для длинной.** На test 256 смесь улучшила обе метрики относительно обеих отдельных моделей. На native test 1k NDCG@10 выросла относительно обеих моделей; Recall@100 по точечной оценке немного выше истории 50, но парный 95% интервал этого прироста включает ноль. Относительно истории 2 обе метрики 1k выросли.

## Нормировка и выбор коэффициента

Для каждого запроса и каждой модели отдельно: `z = (score - mean) / max(std, 1e-8)`, где mean и population std считаются по текущему candidate set. Далее `mixed = (1-alpha) * z50 + alpha * z2`. Согласуются шкалы для ранжирования; вероятности взаимодействия не калибруются. Нормировка использует только scores, не labels; на test применяется та же фиксированная формула. Положительное аффинное преобразование сохраняет порядок отдельной модели. Крайние точки ранжируются по исходным scores для точного воспроизведения прежней арифметики.

У моделей собственные пространства embeddings: смешиваются оценки одних item_id, а не их vectors. Полные score-матрицы существуют только для текущего batch 256; на диск записаны ranks. Нормировка кандидатов по норме item-вектора из прежнего аудита была другим преобразованием и здесь не применяется.

Сетка задана до запуска: α = 0, 0.1, …, 1. Для каждого размера отдельно выбран максимум NDCG@10 на его полной `model_valid`; tie break — меньший α. Recall не ограничивал подбор. Для 256: 29 313 targets / 114 125 кандидатов; для 1k: 100 809 / 244 194. Обе selection записаны и захэшированы **до первой test-оценки**, впоследствии не изменялись. 1k shared использует native-selected α без нового подбора. Нормировка всегда считается по кандидатам соответствующего запроса, включая shared candidate set.

## Test: общая исходная когорта

Одинаковые **45 711 targets у 244 пользователей**, исходные histories 256-пилота, **114 125 кандидатов**. У моделей 2 видны только два последних события; у моделей 50 — исходное окно. Кандидаты 1k сопоставлены по item_id. Все веса и коэффициенты заморожены.

| Пилот | Вариант | NDCG@10 | Recall@100 |
| --- | --- | ---: | ---: |
| 256 | История 50 | 0.026805 | 0.215659 |
| 256 | История 2 | 0.034353 | 0.196649 |
| 256 | Смесь, α = 0.6 | 0.038987 | 0.230579 |
| 1k | История 50 | 0.020536 | 0.203474 |
| 1k | История 2 | 0.022333 | 0.165343 |
| 1k | Смесь, α = 0.6 | 0.026650 | 0.207652 |

У 256 относительно лучшего отдельного NDCG (история 2) прирост **13.5%**; относительно лучшего отдельного Recall (история 50) — **6.9%**. Все четыре парных интервала разниц выше нуля. У 1k NDCG выше обеих отдельных моделей; прирост Recall над историей 50 по этой когорте неубедителен. Между смесями разных пилотов сохраняется отставание 1k: около **31.6% NDCG** и **9.9% Recall**. Это сравнение на исходной когорте; training vocabulary и состав train/validation между пилотами различаются.

## Проверки и воспроизводимость

- 34 теста прошли: независимые embedding spaces, маска короткого входа, tie break, выбор по NDCG, инвариантность нормировки к положительному масштабу/offset и CPU/MPS.
- Подтверждены hashes четырёх checkpoints и 14 файлов двух датасетов. Базовый код моделей не менялся. Validation endpoints совпали с training logs; все test ranks на α = 0 и α = 1 **побитово совпали** с прежними отдельными моделями во всех трёх scopes.
- Selection hashes до test совпали с hashes после него. На 32 test-событиях (16 повторов / 16 неповторов) в каждом scope выбранная смесь дала одинаковые CPU/MPS ranks.
- Нового обучения и optimizer steps нет. Коэффициент задаётся отдельно для каждого размера; одинаковое значение 0.6 получено независимо. Нормировка не интерпретируется как вероятностная калибровка.

Время diagnostic scoring test: 256 native **14.98 с**, 1k native **99.14 с**, 1k shared **12.46 с**. Оно включает два encoder, две матрицы scores, нормировку и ранжирование трёх весов, включая контрольные endpoints. Это **не benchmark одного production-предсказания**. Прототип использует две отдельные модели и две item-таблицы; сокращение compute/памяти смесью не заявляется.

Нормированная смесь дала полезный прототип длинной и короткой ветвей для следующей проверки устаревания длинного представления при свежей короткой истории. Это ещё не эксперимент с cache age или refresh-политиками. Один seed и уже использовавшийся в пилотных исследованиях test ограничивают обобщение вывода; α после test не менялся. Raw-score смесь и вероятность взаимодействия в этом эксперименте не исследовались.
